# 🏆 Calculadora de Partidas Rankeadas

## 📌 Sobre o Projeto
Este é um projeto desenvolvido para calcular o saldo de partidas ranqueadas com base no número de vitórias e derrotas. A aplicação determina o nível do jogador conforme sua quantidade de vitórias, oferecendo uma interface simples e intuitiva.

## 🚀 Tecnologias Utilizadas
- HTML
- CSS
- JavaScript

## 🎯 Funcionalidades
- Entrada de dados (vitórias e derrotas)
- Cálculo do saldo de vitórias
- Determinação do nível do jogador baseado no saldo
- Exibição do resultado de forma dinâmica na interface
